# Docx to Handwriting App

A simple Streamlit web application that converts `.docx` files into realistic handwritten note images using Python, `python-docx`, and `Pillow`.

## How to Run Locally
1. Clone the repository:
   ```bash
   git clone [https://github.com/your-username/docx-to-handwriting.git](https://github.com/your-username/docx-to-handwriting.git)
   cd docx-to-handwriting
